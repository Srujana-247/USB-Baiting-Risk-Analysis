# USB Baiting – Cybersecurity Risk Analysis

## Project Overview

This project is based on a fictional cybersecurity scenario involving a suspicious USB flash drive discovered in the parking lot of Rhetorical Hospital.

The exercise focuses on understanding USB baiting attacks, identifying sensitive information that could be exposed through removable media, evaluating potential security threats, and recommending preventive security controls.

## Scenario

A USB drive carrying the hospital's logo was discovered in the parking lot. Upon examination in an isolated virtual environment, the device appeared to contain personal and professional information belonging to the hospital's Human Resources Manager, Jorge Bailey.

The scenario highlights how attackers can exploit human curiosity and unsecured removable media to gain access to organizational systems or obtain sensitive information.

Refer to the `Scenario` folder for the detailed scenario summary.

## Objectives

- Understand USB baiting and social engineering techniques.
- Identify personally identifiable information (PII).
- Analyse potential threats to individuals and organizations.
- Understand the impact of malware and unauthorized access.
- Recommend security controls to reduce removable-media risks.

## Risk Analysis

The exercise considers the following potential threats:

- Ransomware and spyware infections.
- Exposure of employee and patient information.
- Credential theft and unauthorized access.
- Social engineering and targeted phishing.
- Disruption of hospital operations and reputational damage.

## Recommended Security Controls

- Disable AutoRun/AutoPlay for removable devices.
- Implement endpoint protection and removable-media scanning.
- Restrict unauthorized USB devices.
- Establish removable-media security policies.
- Conduct regular employee security awareness training.
- Encourage employees to report unidentified USB devices.

## Skills Demonstrated

- Basic cybersecurity risk assessment
- Threat identification
- Social engineering awareness
- PII identification
- Security control recommendations
- Cybersecurity documentation

## Learning Outcome

This exercise helped develop an understanding of how seemingly harmless physical devices can introduce cybersecurity risks. It also highlighted the importance of employee awareness, organizational policies, and technical security controls in protecting sensitive information.
